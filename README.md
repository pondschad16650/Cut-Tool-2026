Yes, you can transfer the VideoPatch executable to other Windows machines. The patch is applied locally to each computer's installed software.

### I get an error when trying to patch. What should I do?

First, ensure your anticomponent software hasn't quarantined the executable. Second, verify you are using the latest version of VideoPatch. Finally, check that you have administrator rights and that the target editor is fully closed.
